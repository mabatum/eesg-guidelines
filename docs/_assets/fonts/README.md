Fonts used by the EESG reading theme:

- Lora, normal variable font (400–700), by Cyreal. Cyrillic extension by Alexei Vanyashin and Olga Karpushina. Source: https://github.com/google/fonts/tree/main/ofl/lora
- Inter, normal and italic variable fonts (100–900), by Rasmus Andersson and contributors. Source: https://github.com/google/fonts/tree/main/ofl/inter

Retrieved on 2026-09-06. The source TTF files were losslessly packaged as WOFF with fontTools. No outlines, character mappings or font names were changed. Each file includes the full Russian alphabet, including Ё/ё, verified against its Unicode cmap.

Both families are distributed under the SIL Open Font License 1.1. The complete notices are in `lora-OFL.txt` and `inter-OFL.txt`. These fonts are served from the site itself; the theme does not load font files from external services.
