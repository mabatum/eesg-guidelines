# Отдельные клинические ситуации

**Статус:** Тестовая версия · **Обновлено:** 13.08.2026


## Введение

Раздел посвящён межнозологическим клиническим ситуациям, при которых выбор диагностической и лечебной тактики определяется не только морфологическим типом и стадией саркомы, но также обстоятельствами предшествующего вмешательства, характером распространения заболевания, возрастом, функциональным состоянием, репродуктивными задачами или наследственной предрасположенностью.
