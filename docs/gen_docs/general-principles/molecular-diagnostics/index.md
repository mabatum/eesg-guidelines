# Молекулярная диагностика и высокопроизводительное секвенирование

**Статус:** Тестовая версия · **Обновлено:** 16.08.2026


Молекулярное исследование решает две разные задачи: подтверждает нозологический
диагноз и — гораздо реже — указывает мишень для терапии. Показания к ним разные
и смешивать их нельзя.

## Молекулярное подтверждение диагноза

**Для подтипов с определяющей генетической перестройкой молекулярное исследование входит в диагностический стандарт и уточняющей процедурой не является.** [[1]](https://doi.org/10.1002/cncr.11840)

> Среди наблюдений, направленных с подозрением на синовиальную саркому,
> транскрипт SYT-SSX выявлен лишь в половине случаев; пригодная РНК получена в
> 87 % образцов.

| Подтип | Перестройка | Химерный ген | Метод |
|---|---|---|---|
| Синовиальная саркома | t(X;18)(p11;q11) | SS18::SSX1, SS18::SSX2, SS18::SSX4 | FISH, NGS |
| Саркома Юинга | t(11;22)(q24;q12) | EWSR1::FLI1 | FISH, NGS |
| Миксоидная липосаркома | t(12;16)(q13;p11) | FUS::DDIT3 | FISH, NGS |
| Альвеолярная рабдомиосаркома | t(2;13)(q35;q14) | PAX3::FOXO1 | FISH, NGS |
| Дерматофибросаркома протуберанс | t(17;22)(q22;q13) | COL1A1::PDGFB | FISH |
| Светлоклеточная саркома | t(12;22)(q13;q12) | EWSR1::ATF1 | FISH, NGS |
| Внескелетная миксоидная хондросаркома | t(9;22)(q22;q12) | EWSR1::NR4A3 | FISH, NGS |
| Десмопластическая мелкокруглоклеточная опухоль | t(11;22)(p13;q12) | EWSR1::WT1 | FISH, NGS |
| Липоматозные опухоли | амплификация 12q13-15 | MDM2, CDK4 | FISH [[2]](https://doi.org/10.1097/PAS.0b013e3180581fff) |

**При липоматозных опухолях амплификация MDM2 определяется гибридизацией in situ, а не иммуногистохимически.** [[2]](https://doi.org/10.1097/PAS.0b013e3180581fff)

> При прямом сравнении на одном материале гибридизация оказалась чувствительнее
> и специфичнее полимеразной цепной реакции и иммуногистохимии; результат
> интерпретируем в 90 % случаев.

**Отсутствие ожидаемой перестройки при убедительной морфологии требует пересмотра диагноза.** — согласованное мнение рабочей группы

| Объяснение отрицательного результата | Что делать |
|---|---|
| Иной подтип | пересмотр морфологии в референсном центре |
| Редкий вариант перестройки, не выявляемый тест-системой | секвенирование вместо гибридизации |
| Недостаточное качество нуклеиновых кислот | повторное исследование, при необходимости повторный забор |

## Саркомы, ассоциированные с транслокацией

**Саркомы делятся на опухоли с простым кариотипом и определяющей перестройкой и опухоли со сложным кариотипом без специфического маркера.** [[3]](https://doi.org/10.1016/j.cell.2013.02.036)

> В первой группе белок слияния присутствует практически во всех опухолевых
> клетках и отсутствует в нормальных тканях, служа одновременно диагностическим
> критерием и движущим онкогенным событием.

**Онкогенез при них связан с нарушением работы хроматин-ремоделирующих комплексов, а не с активацией отдельной киназы; ингибиторы киназ при таких опухолях неэффективны.** [[3]](https://doi.org/10.1016/j.cell.2013.02.036)

**Принадлежность к группе учитывается при выборе терапии распространённого заболевания.** [[4]](https://doi.org/10.1016/S1470-2045(15)70098-7)

> Трабектедин в популяции, отобранной по признаку транслокации, увеличил медиану
> выживаемости без прогрессирования с 0,9 до 5,6 месяца (ОР 0,07; 95 % ДИ
> 0,03–0,16).

**Молекулярная группа нозологический диагноз не заменяет: тактика определяется подтипом.** — согласованное мнение рабочей группы

## Панельное секвенирование

**Выполняется при распространённом заболевании после исчерпания стандартных линий либо при неясном морфологическом диагнозе.** — согласованное мнение рабочей группы

> При локализованном заболевании тактику не меняет: объём операции и показания к
> облучению определяются размером, глубиной и степенью злокачественности.

| Находка при секвенировании 44 гистологических типов | Частота [[5]](https://doi.org/10.1038/s41467-022-30496-0) |
|---|---|
| Уточнение или переназначение нозологического диагноза | 10,5 % |
| Потенциально значимое для терапии изменение | 31,7 % |
| Перестройка гена киназы | 2,6 % |
| Мутационная нагрузка 10 и более на мегабазу | 3,9 % |
| Микросателлитная нестабильность | ниже 0,3 % |

**Микросателлитная нестабильность рутинно не определяется.** [[5]](https://doi.org/10.1038/s41467-022-30496-0)

> При частоте ниже 0,3 % доля ложноположительных результатов сопоставима с долей
> истинных.

**Профилирование метилирования применяется как дополнительный метод при неразрешённом морфологическом диагнозе.** [[6]](https://doi.org/10.1002/cjp2.215)

> При независимой проверке классификатор дал заключение для 55 % образцов,
> совпадение с морфологическим диагнозом — в 83 % из них.

## Терапевтически значимые находки

**Слияние гена NTRK — основание для назначения ингибитора TRK независимо от гистологического типа.** [[7]](https://doi.org/10.1056/NEJMoa1714448) [[8]](https://doi.org/10.1016/S1470-2045(19)30691-6)

> Частота объективного ответа 75 % (95 % ДИ 61–85) при 17 гистологических типах.
> Слияния при саркомах редки, поэтому исследование выполняется при исчерпании
> стандартных вариантов, а не рутинно.

## Ограничения доказательной базы

**Польза молекулярного профилирования доказана для диагноза, а не для выживаемости; переход от находки к результату лечения подтверждён только для отдельных мишеней.** — согласованное мнение рабочей группы

**Результаты классификаторов и панелей получены в референсных лабораториях; вне их доля неинтерпретируемых результатов выше, поэтому потребность в свежем или правильно фиксированном материале определяется до биопсии.** — согласованное мнение рабочей группы

## Сопоставление с действующими руководствами

| Сообщество | Позиция о молекулярной диагностике |
|---|---|
| ESMO | молекулярное исследование дополняет морфологию в четырёх случаях: диагноз сомнителен, картина необычна, результат прогностически или предсказательно значим, нозология определена через молекулярное нарушение; требует участия лаборатории во внешней оценке качества; отдельно — исследование зародышевых вариантов TP53 при саркоме до 46 лет с соответствующим семейным анамнезом |
| NCCN | по первоисточнику не сверялось |
| Британское руководство (BSG) | секвенирование применяет для подтверждения патогномоничных нарушений; в Англии полногеномное исследование оплачивается государством, для чего при биопсии дополнительно берут материал для заморозки и кровь для исследования зародышевых вариантов |
| Немецкое руководство (GGPO) | при опухолях с определяющим нарушением требует молекулярного подтверждения, при невозможности — направления в специализированную лабораторию (сильный консенсус); при неожиданной генетической находке — второго морфологического мнения |
| Рабочая группа EESG | панельное секвенирование — после исчерпания стандартных вариантов; микросателлитная нестабильность рутинно не определяется |

> Расхождение — в сроках широкого секвенирования, а не в его составе: британская
> модель предполагает полногеномное исследование уже при диагностике и обеспечена
> финансированием.
