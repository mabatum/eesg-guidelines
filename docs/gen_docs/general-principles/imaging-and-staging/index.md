# Визуализация, стадирование и оценка риска

## Введение

Визуализация до биопсии определяет анатомический компартмент, жизнеспособный участок и безопасную траекторию доступа. Для опухолей конечностей и поверхностного туловища основным методом локальной оценки является магнитно-резонансная томография; для забрюшинных, внутригрудных и внутрибрюшных образований применяют компьютерную томографию с внутривенным контрастированием [руководство Великобритании 2024 года](https://pmc.ncbi.nlm.nih.gov/articles/PMC11724041/).

## Первичная локальная визуализация

Протокол магнитно-резонансной томографии включает последовательности, позволяющие определить размеры в трёх плоскостях, отношение к фасциям, сосудам, нервам, кости и суставу, зоны некроза, отёк и сателлитные очаги. В заключении указывают участок для биопсии и факторы, влияющие на резектабельность; исходные изображения сохраняют для сравнения [рекомендации ESSR 2024 года](https://pmc.ncbi.nlm.nih.gov/articles/PMC12081562/).

Ультразвуковое исследование используется для первичной сортировки поверхностных образований. При неопределённом результате выполняют магнитно-резонансную томографию; диагностическая точность ультразвука зависит от подготовки оператора, поэтому единый показатель чувствительности для всех условий не установлен [руководство Великобритании](https://pmc.ncbi.nlm.nih.gov/articles/PMC11724041/).

## Системное стадирование

После подтверждения саркомы мягких тканей промежуточной или высокой степени выполняют компьютерную томографию органов грудной клетки. Объём исследования расширяют до живота и таза при забрюшинной, висцеральной локализации или гистологическом типе с внепульмональным распространением [руководство Великобритании](https://pmc.ncbi.nlm.nih.gov/articles/PMC11724041/).

Регионарные лимфатические узлы исследуют при клиническом подозрении и при гистологических типах с лимфогенным метастазированием. Визуализация головного мозга показана при неврологических симптомах, а также рассматривается при альвеолярной мягкотканной и светлоклеточной саркомах; рутинное исследование головного мозга для всех сарком мягких тканей не обосновано [руководство Великобритании](https://pmc.ncbi.nlm.nih.gov/articles/PMC11724041/).

Позитронно-эмиссионная томография, совмещённая с компьютерной томографией, не заменяет стандартное стадирование для всех гистологических типов. Метод применяется для отдельных диагностических задач, оценки подозрения на злокачественную опухоль оболочек периферического нерва при NF1 и планирования радикального локального лечения в отобранных случаях; точный прирост клинической пользы для неселектированной популяции не установлен [руководство Великобритании](https://pmc.ncbi.nlm.nih.gov/articles/PMC11724041/).

## Стадия и прогноз

Стадию указывают по применимой версии TNM UICC/AJCC. Для индивидуального прогноза дополнительно учитывают гистологический тип, степень FNCLCC, размер, глубину, локализацию, возраст, резектабельность, разрыв опухоли, края и распределение метастазов [руководство Великобритании](https://pmc.ncbi.nlm.nih.gov/articles/PMC11724041/).

Номограммы применяют только в популяции, в которой они валидированы. Sarculator и другие модели дают вероятностную оценку для конкретных локализаций и исходов, но не заменяют клиническое решение; калибровка модели в иной популяции может отличаться [Callegaro и соавт., 2016](https://doi.org/10.1016/S1470-2045(16)00010-4).

## Оценка эффекта лечения

Изменение размеров по критериям оценки ответа при солидных опухолях версии 1.1 остаётся стандартным показателем в исследованиях солидных опухолей. При миксоидных опухолях, гастроинтестинальной стромальной опухоли и отдельных таргетных воздействиях размеры могут не отражать изменение плотности, сигнала или метаболической активности; дополнительные критерии применяются только в нозологически валидированном контексте [критерии оценки ответа при солидных опухолях версии 1.1](https://doi.org/10.1016/j.ejca.2008.10.026).

## Ограничения данных

Большинство рекомендаций по объёму стадирования основано на ретроспективных сериях и экспертном согласии. Сравнительных исследований, определяющих единый оптимальный набор исследований для всех гистологических типов, нет [руководство Великобритании](https://pmc.ncbi.nlm.nih.gov/articles/PMC11724041/).
