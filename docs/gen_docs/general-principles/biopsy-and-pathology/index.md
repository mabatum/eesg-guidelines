# Биопсия и патоморфологическая диагностика

**Статус:** Тестовая версия · **Обновлено:** 16.08.2026


Морфологический диагноз получают до начала любого лечения. Ошибка на этом этапе
меняет объём последующей операции и исход.

## Кто и где выполняет биопсию

**Биопсия выполняется в том учреждении, где планируется лечение.** [[1]](https://doi.org/10.2106/00004623-199605000-00004)

> При биопсии в направляющем учреждении диагностическая ошибка отмечена в
> 17,8 % случаев, вынужденное изменение операции или добавление лучевой либо
> лекарственной терапии — в 19,3 %, изменение исхода вплоть до потери функции,
> рецидива или смерти — в 10,1 %; это в два–двенадцать раз чаще, чем в лечебном
> центре.

**Траектория согласуется с хирургом до вмешательства и располагается так, чтобы её можно было удалить единым блоком с опухолью.** — согласованное мнение рабочей группы

> Требование вытекает из необходимости сохранить возможность радикальной
> резекции: прямых данных о том, что иссечение траектории снижает частоту
> местного рецидива, нет.

## Метод получения материала

**Стандарт первичной диагностики — пункционная биопсия толстой иглой под контролем визуализации.** [[2]](https://doi.org/10.1002/cncr.32735) [[3]](https://doi.org/10.1038/s41598-021-96953-w)

| Показатель | Пункционная толстой иглой | Инцизионная |
|---|---|---|
| Чувствительность, злокачественность | 97 % | 96 % |
| Специфичность, злокачественность | 99 % | 100 % |
| Чувствительность, подтип | 88 % | 93 % |
| Специфичность, подтип | 77 % | 65 % |
| Осложнения при прямом сравнении | не отмечены | тромбоэмболия лёгочной артерии, инфекция области вмешательства [[3]](https://doi.org/10.1038/s41598-021-96953-w) |

**Инцизионная биопсия выполняется, когда пункционная неинформативна, и назначается после обсуждения в специализированном центре.** [[3]](https://doi.org/10.1038/s41598-021-96953-w)

**Тонкоигольная аспирационная биопсия как единственный метод первичной классификации не используется.** — согласованное мнение рабочей группы

> Материала недостаточно для оценки степени злокачественности, архитектуры и
> молекулярного исследования. Допустимое применение — подтверждение рецидива
> или поражения лимфатического узла при установленном диагнозе.

**При забрюшинной локализации пункционная биопсия безопасна.** [[4]](https://doi.org/10.1245/s10434-019-07656-6)

> Кровотечение без потребности в переливании 2 %, выраженная боль 0,8 %,
> незапланированная госпитализация 0,3 %, пневмоторакс 0,3 %; инфекционных
> осложнений не было.

**Обнаружение опухолевых клеток в траектории с повышением частоты местного рецидива не связано.** [[5]](https://doi.org/10.1007/s11999-016-5090-y)

> Данные ретроспективные и получены там, где траекторию иссекали при первой
> возможности; вопрос о допустимости её сохранения ими не решается.

## Патоморфологическое заключение

**Состав заключения по биопсийному материалу.** — согласованное мнение рабочей группы

| Пункт |
|---|
| Нозология по действующей классификации ВОЗ |
| Степень злокачественности по FNCLCC |
| Митотический счёт отдельной строкой |
| Наличие и объём некроза |
| Результаты иммуногистохимического и молекулярного исследования |
| Оценка репрезентативности материала |

**Дополнительно в заключении по операционному материалу.** — согласованное мнение рабочей группы

| Пункт |
|---|
| Размер опухоли |
| Целость препарата, разрыв опухоли до или во время операции |
| Состояние каждого края резекции |
| Расстояние до ближайшего края в миллиметрах |
| Анатомическая структура, формирующая этот край |
| При предоперационном лечении — доля жизнеспособной опухоли |

> Формулировка R0 или R1 без расстояния и анатомического субстрата края для
> планирования облучения и повторной операции недостаточна.

**Степень злокачественности определяется по системе FNCLCC.** [[6]](https://doi.org/10.1200/JCO.1997.15.1.350)

> В многофакторной модели FNCLCC имела больший прогностический вес, чем вторая
> система, и превосходила по предсказательной силе размер и глубину залегания.

**Степень злокачественности после предоперационной лекарственной или лучевой терапии исходной не приравнивается.** — согласованное мнение рабочей группы

> Лечебный патоморфоз изменяет все три компонента системы: клеточность,
> митотическую активность и объём некроза.

## Незапланированное удаление опухоли

**Остаточная опухоль обнаруживается примерно у трети больных даже при отсутствии её признаков клинически и при визуализации.** [[7]](https://doi.org/10.2106/00004623-199605000-00003)

> При повторной резекции опухоль выявлена в 35 % случаев; макроскопически
> подозрительные узлы подтверждались морфологически в 59 %, а часть опухолей
> обнаружена там, где макроскопических изменений не было.

**Незапланированное удаление повышает риск местного рецидива, но не влияет на отдалённые метастазы и общую выживаемость.** [[8]](https://doi.org/10.1245/s10434-020-09564-6)

> Семилетняя выживаемость 73,8 % при первичной радикальной операции, 84,1 %
> после повторной резекции вслед за макроскопически полным незапланированным
> удалением, 80,7 % после неполного.

## Ограничения доказательной базы

**Универсальные число столбиков и диаметр иглы не установлены; при миксоидных и высокодифференцированных липоматозных опухолях малый объём материала систематически занижает степень злокачественности.** — согласованное мнение рабочей группы

**Сравнения методов биопсии не рандомизированы: инцизионная чаще выполнялась после неинформативной пункционной, что смещает оценку не в её пользу.** — согласованное мнение рабочей группы

## Сопоставление с действующими руководствами

| Сообщество | Позиция о биопсии и патоморфологическом заключении |
|---|---|
| ESMO | пункционная биопсия толстой иглой — метод выбора; открытая — в отдельных случаях по решению референсного центра; выполняет хирург или радиолог после консилиума; траектория и рубец должны удаляться при радикальной операции, кроме забрюшинных сарком; точку входа допустимо татуировать; срочное исследование пригодно для оценки информативности, но не для диагноза; степень злокачественности после предоперационного лечения не определяется |
| NCCN | по первоисточнику не сверялось |
| Британское руководство (BSG) | морфологический диагноз до лечения — чрескожной биопсией толстой иглой с пересмотром специализированным патоморфологом; отмечает занижение степени злокачественности по столбику из-за гетерогенности и недостаточного представительства некроза |
| Немецкое руководство (GGPO) | тонкоигольную аспирационную биопсию для первичной диагностики не рекомендует: малый объём материала делает невозможным референсный пересмотр |
| Рабочая группа EESG | биопсия выполняется в лечащем учреждении; траектория иссекается, если это выполнимо без расширения объёма |

> Расхождение одно — обязательность иссечения траектории: ESMO закладывает её в
> планирование как правило, тогда как приведённые данные связи с местным
> рецидивом не показывают.
