# Периоперационная химиотерапия локализованных сарком мягких тканей

**Статус:** Тестовая версия · **Обновлено:** 16.08.2026


Рутинное назначение всем больным группы высокого риска выживаемость не
улучшает. Практический вопрос — не «назначать ли вообще», а «кому именно».

## Кому назначается

| Условие | Решение |
|---|---|
| Расчётная десятилетняя общая выживаемость ниже 60 % по номограмме | обсуждается назначение [[1]](https://doi.org/10.1016/j.ejca.2018.12.009) |
| Промежуточный и благоприятный расчётный прогноз | не назначается [[1]](https://doi.org/10.1016/j.ejca.2018.12.009) |
| Альвеолярная саркома мягких тканей, светлоклеточная саркома | не назначается: подтипы устойчивы к антрациклину с ифосфамидом |
| Забрюшинная и висцеральная локализация | данные не переносятся, решение индивидуальное |
| Недостаточный объём операции | не назначается: химиотерапия его не компенсирует |

**Выигрыш ограничен больными с наихудшим расчётным прогнозом.** [[1]](https://doi.org/10.1016/j.ejca.2018.12.009)

> При расчётной десятилетней выживаемости ниже 60 % химиотерапия вдвое снижала
> риск рецидива и смерти (ОР 0,46 и 0,50); в остальных группах эффекта нет.
> Анализ ретроспективный.

**В решении консилиума фиксируется расчётный прогноз, послуживший основанием.** — согласованное мнение рабочей группы

## Режим и сроки

| Параметр | Значение |
|---|---|
| Режим | антрациклин с ифосфамидом [[2]](https://doi.org/10.1016/S1470-2045(17)30334-0) [[3]](https://doi.org/10.1093/annonc/mdu460) |
| Число курсов | не менее трёх; три не уступают пяти |
| Сроки | предоперационно |
| Дозы в исследовании, показавшем выигрыш | эпирубицин 120 мг/м², ифосфамид 9 г/м² |
| Подбор режима по гистологическому типу | не выполняется |

**Предоперационное назначение предпочтительнее послеоперационного.** — согласованное мнение рабочей группы

> Позволяет оценить чувствительность опухоли, не откладывается на период
> заживления и не отменяется из-за послеоперационных осложнений. Прямого
> рандомизированного сравнения последовательности не проводилось.

**Подбор режима по гистологическому типу хуже стандартного режима.** [[2]](https://doi.org/10.1016/S1470-2045(17)30334-0) [[4]](https://doi.org/10.1200/JCO.19.03289)

> Трёхлетняя выживаемость без признаков болезни 62 % при стандартном режиме и
> 38 % при подобранном по подтипу (ОР 2,00; 95 % ДИ 1,22–3,26); набор прекращён
> досрочно. Результат относится к сравнивавшимся режимам, а не к идее подбора.

## Что показали рандомизированные исследования

| Исследование | Результат |
|---|---|
| Доксорубицин с ифосфамидом против наблюдения [[5]](https://doi.org/10.1016/S1470-2045(12)70346-7) | 5-летняя ОВ 66,5 % против 67,8 % (ОР 0,94; 95 % ДИ 0,68–1,31); различий нет |
| Интенсифицированный режим [[6]](https://doi.org/10.1200/JCO.2001.19.5.1238) | медиана ОВ 75 против 46 месяцев; исследование мало, остановлено досрочно, контрольная группа хуже ожидаемой |
| Режим по гистологическому типу [[2]](https://doi.org/10.1016/S1470-2045(17)30334-0) [[4]](https://doi.org/10.1200/JCO.19.03289) | хуже стандартного |

## Ограничения доказательной базы

**Отбор по расчётному прогнозу проспективно не проверен: анализ выполнен на данных завершённого исследования.** [[1]](https://doi.org/10.1016/j.ejca.2018.12.009)

**Результаты отдельных исследований противоречат друг другу; различия в критериях включения, режимах и качестве хирургического этапа сопоставимы по величине с изучаемым эффектом.** — согласованное мнение рабочей группы

**Данные получены преимущественно при саркомах конечностей и туловища.** — согласованное мнение рабочей группы

## Сопоставление с действующими руководствами

| Сообщество | Позиция о периоперационной химиотерапии |
|---|---|
| ESMO | допускает антрациклин с ифосфамидом при расчётной десятилетней выживаемости ниже 60 %; предоперационно не менее трёх курсов; адъювантную химиотерапию для компенсации недостаточной операции запрещает; при альвеолярной саркоме и светлоклеточной саркоме не назначает; при миксоидной липосаркоме рассматривает трабектедин; региональную гипертермию считает подтверждённой рандомизированно |
| NCCN | по первоисточнику не сверялось |
| Британское руководство (BSG) | предоперационное назначение считает способом прояснить вопрос о пользе; при забрюшинной дедифференцированной липосаркоме и лейомиосаркоме относит к предмету продолжающегося исследования |
| Немецкое руководство (GGPO) | стандартом не считает; возможные показания — G3, глубокое расположение, размер более 5 см, а также забрюшинная локализация с высоким риском местного рецидива |
| Рабочая группа EESG | пользу ограничивает наихудшим расчётным прогнозом; подбор режима по гистологическому типу не рекомендует |

> Расхождений нет: порог отбора, предпочтение предоперационного назначения и
> отказ от подбора режима по подтипу совпадают.
