# Первичные саркомы сердца

**Статус:** Тестовая версия · **Обновлено:** 17.08.2026


| Показатель | Значение |
|---|---|
| Самый частый подтип | интимальная саркома [[1]](https://doi.org/10.1097/PAS.0000000000000184) |
| Правые отделы | почти все ангиосаркомы [[1]](https://doi.org/10.1097/PAS.0000000000000184) |
| Левые отделы | 83 % интимальных сарком [[1]](https://doi.org/10.1097/PAS.0000000000000184) |
| Молекулярный признак интимальной саркомы | амплификация MDM2 [[1]](https://doi.org/10.1097/PAS.0000000000000184) |
| Что улучшает выживаемость | удаление опухоли и химиотерапия [[2]](https://doi.org/10.1016/j.jtcvs.2019.12.109) |
| Медиана выживаемости по популяционным данным | 7 месяцев [[2]](https://doi.org/10.1016/j.jtcvs.2019.12.109) |
| Медиана выживаемости при мультимодальном лечении в центре | 37,5 месяца [[3]](https://doi.org/10.1186/s40959-025-00359-w) |

## Определение и классификация

**Гистологический подтип предсказывается локализацией опухоли в сердце.** [[1]](https://doi.org/10.1097/PAS.0000000000000184)

| Отдел | Подтип [[1]](https://doi.org/10.1097/PAS.0000000000000184) |
|---|---|
| Правые отделы | ангиосаркома: 25 из 26 наблюдений |
| Левые отделы | интимальная саркома: 83 % наблюдений; недифференцированная саркома: 72 % |

**Интимальная саркома подтверждается амплификацией MDM2.** [[1]](https://doi.org/10.1097/PAS.0000000000000184)

> Гиперэкспрессия MDM2 при иммуногистохимии обнаруживается и у части
> недифференцированных сарком и ангиосарком, тогда как амплификация выявлена
> только при интимальной саркоме. Диагноз ставится по амплификации, а не по
> окрашиванию.

**Опухоль в левом предсердии, принимаемая за миксому, требует морфологического подтверждения.** [[4]](https://doi.org/10.1080/14737140.2020.1711738)

## Диагностика

| Что | Когда |
|---|---|
| Эхокардиография | всем: первый метод выявления образования |
| МРТ сердца | всем: отличает опухоль от тромба и миксомы, показывает инвазию |
| КТ органов грудной клетки, брюшной полости и таза | всем |
| МРТ головного мозга | всем: метастазы в головной мозг при этой локализации нередки [[4]](https://doi.org/10.1080/14737140.2020.1711738) |
| Морфологическое подтверждение до начала лечения | всем, если это не задерживает операцию по жизненным показаниям |
| Определение амплификации MDM2 | при подозрении на интимальную саркому [[1]](https://doi.org/10.1097/PAS.0000000000000184) |

**МРТ головного мозга выполняется при первичном обследовании.** [[4]](https://doi.org/10.1080/14737140.2020.1711738)

> Это отличает нозологию от прочих сарком мягких тканей, где визуализация
> головного мозга в стандартный объём стадирования не входит.

**Лечение планируется совместно с кардиохирургом до первого вмешательства.** — согласованное мнение рабочей группы

## Локализованное заболевание

**Основной метод — удаление опухоли с чистым краем.** [[2]](https://doi.org/10.1016/j.jtcvs.2019.12.109) [[3]](https://doi.org/10.1186/s40959-025-00359-w)

| Показатель [[2]](https://doi.org/10.1016/j.jtcvs.2019.12.109) | Значение |
|---|---|
| Удаление опухоли | отношение рисков 0,49 (95 % ДИ 0,37–0,64) |
| Химиотерапия | отношение рисков 0,70 (95 % ДИ 0,54–0,92) |
| Медиана общей выживаемости | 7 месяцев |
| Выживаемость через 1, 3 и 5 лет | 40,7 %, 15,6 %, 9,8 % |

**Предоперационная химиотерапия рассматривается, когда она может сделать удаление выполнимым.** [[4]](https://doi.org/10.1080/14737140.2020.1711738) [[3]](https://doi.org/10.1186/s40959-025-00359-w)

> В когорте специализированного центра системную терапию получили 73 % больных,
> и медиана общей выживаемости составила 37,5 месяца против 7 месяцев по
> популяционным данным. Различие в значительной мере отражает отбор.

**Полное удаление при поражении левых отделов достижимо чаще, чем при поражении правых.** [[1]](https://doi.org/10.1097/PAS.0000000000000184)

**Послеоперационная лучевая терапия обсуждается при нерадикальном удалении.** — согласованное мнение рабочей группы

**Трансплантация сердца стандартом не является.** — согласованное мнение рабочей группы

## Распространённое заболевание

**Лечение определяется гистологическим подтипом.** [[5]](https://doi.org/10.1002/cncr.26599) [[6]](https://doi.org/10.1016/S1470-2045(14)70063-4)

| Подтип | Первая линия |
|---|---|
| Ангиосаркома | еженедельный паклитаксел либо доксорубицин [[5]](https://doi.org/10.1002/cncr.26599) |
| Интимальная и недифференцированная саркома | доксорубицин, при необходимости быстрого ответа — с ифосфамидом [[6]](https://doi.org/10.1016/S1470-2045(14)70063-4) |
| Синовиальная саркома | по правилам для соответствующего подтипа |

> Подробнее — на страницах
> [Ангиосаркома](../../soft-tissue-sarcomas/angiosarcoma/index.md) и
> [Системная терапия распространённых сарком мягких тканей](../../general-principles/systemic-therapy-advanced-sts/index.md).

**Кардиотоксичность антрациклинов оценивается до начала лечения: опухоль и её удаление сами нарушают функцию сердца.** — согласованное мнение рабочей группы

**Ангиосаркома сердца — наиболее неблагоприятный подтип.** [[3]](https://doi.org/10.1186/s40959-025-00359-w)

> В когорте из 33 больных отношение рисков смерти при ангиосаркоме составило
> 6,97, при наличии отдалённых метастазов — 3,74.

## Наблюдение

**Наблюдение включает эхокардиографию или МРТ сердца и компьютерную томографию органов грудной клетки.** — согласованное мнение рабочей группы

> Медиана выживаемости без событий даже при мультимодальном лечении не превышает
> года, поэтому интервалы в первые два года минимальны. Общие интервалы — на
> странице [Наблюдение](../../general-principles/follow-up/index.md).

## Применимость данных, полученных у детей и подростков

**Нозология встречается преимущественно у взрослых среднего возраста; отдельной доказательной базы для детей нет.** [[1]](https://doi.org/10.1097/PAS.0000000000000184) [[2]](https://doi.org/10.1016/j.jtcvs.2019.12.109)

## Ограничения доказательной базы

**Проспективных исследований при этой локализации не проводилось.** [[4]](https://doi.org/10.1080/14737140.2020.1711738)

**Популяционные данные о выигрыше операции и химиотерапии получены из регистра без сведений о радикальности удаления и о режимах.** [[2]](https://doi.org/10.1016/j.jtcvs.2019.12.109)

**Данные центров основаны на десятках наблюдений за два десятилетия и отражают отбор больных, дошедших до специализированного центра.** [[3]](https://doi.org/10.1186/s40959-025-00359-w)

**Морфологическая серия из 100 наблюдений собиралась более тридцати лет, и часть диагнозов пересматривалась ретроспективно.** [[1]](https://doi.org/10.1097/PAS.0000000000000184)

## Сопоставление с действующими руководствами

| Сообщество | Позиция по первичным саркомам сердца |
|---|---|
| ESMO | отдельной позиции по локализации не формулирует |
| NCCN | по первоисточнику не сверялось |
| Британское руководство (BSG) | при саркомах сердца, интимальных саркомах сосудов и ангиосаркомах допускает липосомальный доксорубицин в любой линии, в том числе у больных с нарушенной функцией сердца и после антрациклинов |
| Немецкое руководство (GGPO) | интимальную саркому приводит в морфологической классификации без отдельной позиции по лечению |
| Рабочая группа EESG | МРТ головного мозга включает в первичное обследование; при подозрении на интимальную саркому требует определения амплификации MDM2; план лечения строит совместно с кардиохирургом до первого вмешательства |

> Расхождений нет: подробных позиций по локализации руководства не содержат.
> Включение МРТ головного мозга в первичное обследование и обязательное
> определение амплификации MDM2 сформулированы здесь как требования.
