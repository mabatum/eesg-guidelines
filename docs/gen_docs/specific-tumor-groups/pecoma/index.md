# Периваскулярная эпителиоидноклеточная опухоль

**Статус:** Тестовая версия · **Обновлено:** 17.08.2026


| Показатель | Значение |
|---|---|
| Молекулярная основа | инактивация TSC1 или TSC2 с активацией mTORC1 |
| Альтернативный вариант | перестройка TFE3 у 5–10 %, взаимоисключающая с поражением TSC [[1]](https://doi.org/10.1111/his.15476) |
| Преобладающий пол | женщины |
| Препарат выбора при распространённом заболевании | ингибитор mTOR [[2]](https://doi.org/10.1200/JCO.21.01728) [[3]](https://doi.org/10.1158/1078-0432.CCR-19-0288) |

| Цитотоксическая химиотерапия | малоактивна: объективный ответ 13–20 % [[3]](https://doi.org/10.1158/1078-0432.CCR-19-0288) |

## Определение и классификация

**Опухоль относится к семейству новообразований из периваскулярных эпителиоидных клеток, коэкспрессирующих меланоцитарные и гладкомышечные маркёры.** [[4]](https://doi.org/10.1097/01.pas.0000173232.22117.37)

| Нозология семейства | Замечание |
|---|---|
| Ангиомиолипома | чаще почечная; в этом разделе не рассматривается |
| Лимфангиолейомиоматоз лёгких | ведётся пульмонологом; в этом разделе не рассматривается |
| Светлоклеточная «сахарная» опухоль лёгкого | редка |
| ПЭКома мягких тканей и женских половых органов | предмет настоящей страницы [[4]](https://doi.org/10.1097/01.pas.0000173232.22117.37) |

**Опухоль ассоциирована с туберозным склерозом; при впервые выявленной ПЭКоме собирается анамнез в этом направлении.** — согласованное мнение рабочей группы

**Перестройка TFE3 выделяет отдельную группу: она взаимоисключающа с поражением TSC1/TSC2 и предсказывает низкую эффективность ингибиторов mTOR.** [[1]](https://doi.org/10.1111/his.15476)

## Оценка злокачественного потенциала

**Злокачественный потенциал оценивается по числу настораживающих признаков, а не по одному из них.** [[4]](https://doi.org/10.1097/01.pas.0000173232.22117.37)

| Настораживающий признак [[4]](https://doi.org/10.1097/01.pas.0000173232.22117.37) | Порог |
|---|---|
| Размер опухоли | более 5 см |
| Характер роста | инфильтративный |
| Ядерная градация и клеточность | высокие |
| Митотическая активность | более 1 митоза на 50 полей зрения при большом увеличении |
| Некроз | есть |
| Сосудистая инвазия | есть |

| Категория [[4]](https://doi.org/10.1097/01.pas.0000173232.22117.37) | Условие |
|---|---|
| Доброкачественная | небольшая опухоль без настораживающих признаков |
| Неопределённого злокачественного потенциала | только ядерный полиморфизм либо только крупный размер |
| Злокачественная | два настораживающих признака и более |

**С рецидивом и метастазами наиболее тесно связаны размер, митотическая активность более 1 на 50 полей зрения и некроз.** [[4]](https://doi.org/10.1097/01.pas.0000173232.22117.37)

## Диагностика

| Что | Когда |
|---|---|
| Биопсия с иммуногистохимией: HMB-45, Melan-A, гладкомышечный актин, десмин | всем |
| Молекулярное исследование TSC1, TSC2 и перестройки TFE3 | при злокачественной и неопределённого потенциала опухоли |
| КТ или МРТ первичной области | всем |
| КТ органов грудной клетки | всем |

**Статус TSC2 определяется до назначения ингибитора mTOR: он предсказывает ответ.** [[2]](https://doi.org/10.1200/JCO.21.01728)

**Перестройка TFE3 определяется в том же исследовании: она меняет ожидаемую эффективность лечения.** [[1]](https://doi.org/10.1111/his.15476)

**Диагноз требует пересмотра профильным патоморфологом: опухоль имитирует эпителиоидную лейомиосаркому, меланому, эпителиоидную гастроинтестинальную стромальную опухоль и почечноклеточный рак.** — согласованное мнение рабочей группы

## Локализованное заболевание

**Основной метод — полное удаление опухоли.** — согласованное мнение рабочей группы

**Адъювантная лекарственная терапия не назначается.** — согласованное мнение рабочей группы

**При нерезектабельной опухоли или при опухоли, требующей калечащей операции, назначается предоперационная терапия ингибитором mTOR.** [[2]](https://doi.org/10.1200/JCO.21.01728) [[3]](https://doi.org/10.1158/1078-0432.CCR-19-0288)

> Уменьшение опухоли достигается быстро: две трети ответов в исследовании
> наб-сиролимуса зафиксированы к шестой неделе. Это позволяет оценить
> резектабельность в пределах двух-трёх месяцев.

**Лучевая терапия при этой нозологии эффективной не признана и применяется только при невозможности операции.** — согласованное мнение рабочей группы

## Распространённое заболевание

**Препаратом выбора служит ингибитор mTOR.** [[2]](https://doi.org/10.1200/JCO.21.01728) [[3]](https://doi.org/10.1158/1078-0432.CCR-19-0288)

| Наб-сиролимус, режим [[2]](https://doi.org/10.1200/JCO.21.01728) | Значение |
|---|---|
| Доза | 100 мг/м² внутривенно |
| Введения | еженедельно две недели из трёх |

| Показатель [[2]](https://doi.org/10.1200/JCO.21.01728) [[5]](https://doi.org/10.1200/JCO.23.02266) | Значение |
|---|---|
| Частота объективного ответа | 39 % (95 % ДИ 22–58); при окончательном анализе 38,7 % |
| Ответ при мутации TSC2 | 8 из 9 (89 %) |
| Ответ без мутации TSC2 | 2 из 16 (13 %) |
| Медиана выживаемости без прогрессирования | 10,6 месяца (95 % ДИ 5,5–41,2) |
| Медиана длительности ответа | 39,7 месяца |
| Медиана общей выживаемости | 53,1 месяца |

**При недоступности наб-сиролимуса назначается сиролимус или эверолимус.** [[3]](https://doi.org/10.1158/1078-0432.CCR-19-0288) [[6]](https://doi.org/10.1200/JCO.2009.25.2981)

| Лечение [[3]](https://doi.org/10.1158/1078-0432.CCR-19-0288) | Объективный ответ | Медиана выживаемости без прогрессирования |
|---|---|---|
| Ингибиторы mTOR | 41 % | 9 месяцев |
| Гемцитабинсодержащие режимы | 20 % | 3,4 месяца |
| Антрациклинсодержащие режимы | 13 % | 3,2 месяца |
| Антиангиогенные препараты | 8,3 % | 5,4 месяца |

**Цитотоксическая химиотерапия применяется после исчерпания ингибиторов mTOR.** [[3]](https://doi.org/10.1158/1078-0432.CCR-19-0288)

**При перестройке TFE3 ингибитор mTOR может оказаться неэффективным; лечение строится как при саркоме мягких тканей соответствующей степени злокачественности.** [[1]](https://doi.org/10.1111/his.15476)

**Терапия ингибитором mTOR продолжается до прогрессирования: после её прекращения рост возобновляется.** — согласованное мнение рабочей группы

**Удаление ограниченного числа метастазов обсуждается у каждого больного.** — согласованное мнение рабочей группы

## Применимость данных, полученных у детей и подростков

**Нозология встречается и у подростков; отдельной доказательной базы для этой возрастной группы нет, лечение не отличается.** [[1]](https://doi.org/10.1111/his.15476)

## Ограничения доказательной базы

**Регистрационное исследование наб-сиролимуса было несравнительным и включало 34 больных.** [[2]](https://doi.org/10.1200/JCO.21.01728) [[5]](https://doi.org/10.1200/JCO.23.02266)

**Сравнение классов лекарств получено в ретроспективной серии из 53 больных, где выбор терапии не рандомизировали.** [[3]](https://doi.org/10.1158/1078-0432.CCR-19-0288)

**Критерии злокачественного потенциала выведены на 26 наблюдениях с медианой наблюдения 30 месяцев и внешней проверки не проходили.** [[4]](https://doi.org/10.1097/01.pas.0000173232.22117.37)

**Данные о низкой эффективности ингибиторов mTOR при перестройке TFE3 получены на малых сериях и отдельных наблюдениях.** [[1]](https://doi.org/10.1111/his.15476)

## Сопоставление с действующими руководствами

| Сообщество | Позиция по периваскулярной эпителиоидноклеточной опухоли |
|---|---|
| ESMO | приводит сиролимус как активный препарат: объективный ответ 41 %, медиана выживаемости без прогрессирования 9 месяцев по ретроспективной серии |
| NCCN | по первоисточнику не сверялось |
| Британское руководство (BSG) | относит нозологию к плохо отвечающим на химиотерапию и приводит для неё сиролимус и наб-сиролимус |
| Немецкое руководство (GGPO) | связывает нозологию с TSC1/TSC2 и активацией mTORC1; отмечает отсутствие эффективной химиотерапии, возобновление роста после отмены ингибитора mTOR и возможность предоперационного применения |
| Рабочая группа EESG | статус TSC2 и перестройку TFE3 определяет до назначения ингибитора mTOR; при нерезектабельной опухоли назначает предоперационную терапию ингибитором mTOR |

> Расхождений нет. Требование молекулярного исследования до начала лечения
> сформулировано здесь как обязательное: без него нельзя отличить группу с
> ожидаемым ответом 89 % от группы с ответом 13 %.
