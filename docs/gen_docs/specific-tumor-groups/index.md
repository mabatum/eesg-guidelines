# Отдельные нозологические группы

## Введение

Раздел объединяет мезенхимальные опухоли, для которых диагностическая классификация, естественное течение или выбор системного лечения не могут быть полностью определены общим алгоритмом сарком мягких тканей. Для каждой нозологии представлены морфологическая и молекулярная верификация, оценка распространённости, локальное и системное лечение, наблюдение и ограничения опубликованных данных ([рекомендации Британской саркомной группы, 2024](https://doi.org/10.1038/s41416-024-02674-y)).

## Принципы интерпретации

Нозологический диагноз должен опираться на актуальную морфологическую классификацию и, когда это определяет сущность опухоли или выбор лечения, на прямое молекулярное подтверждение. Для медленно растущих опухолей возможность наблюдения оценивают до начала потенциально необратимого лечения; для однораменных исследований частота стабилизации интерпретируется с учётом исходного темпа болезни и отсутствия группы сравнения ([рекомендации Британской саркомной группы, 2024](https://doi.org/10.1038/s41416-024-02674-y); [Stacchiotti и соавт., 2021](https://doi.org/10.1016/j.esmoop.2021.100170)).
