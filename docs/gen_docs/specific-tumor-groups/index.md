# Отдельные нозологические группы

**Статус:** Тестовая версия · **Обновлено:** 16.08.2026


Раздел объединяет опухоли, для которых общий алгоритм ведения сарком мягких
тканей неприменим целиком: либо системная терапия определяется собственной
мишенью, либо естественное течение допускает наблюдение вместо лечения, либо
группа выделена по локализации, а не по гистологическому типу.

**Принадлежность нозологии к этому разделу не означает отступления от общих правил диагностики.** — согласованное мнение рабочей группы

> Морфологическое подтверждение, направление в специализированный центр и
> обсуждение на консилиуме до начала лечения обязательны и здесь; см. раздел
> [Общие принципы](../general-principles/index.md).

## Нозологии с собственной системной терапией

| Нозология | Отличие от общего алгоритма |
|---|---|
| [Гастроинтестинальные стромальные опухоли (ГИСО)](gist/index.md) | терапия определяется мутацией KIT и PDGFRA |
| [Десмоидные опухоли](desmoid-tumors/index.md) | отсутствие метастазирования, наблюдение как первый вариант |
| [Дерматофибросаркома протуберанс (ДФСП)](dfsp/index.md) | иматиниб при слиянии COL1A1::PDGFB |
| [Солитарная фиброзная опухоль](solitary-fibrous-tumor/index.md) | антиангиогенная терапия, поздние рецидивы |
| [Саркома Капоши](kaposi-sarcoma/index.md) | вирусная этиология, зависимость тактики от иммунного статуса |

## Группы, выделенные по локализации

| Группа | Почему выделена |
|---|---|
| [Саркомы головы и шеи](head-and-neck-sarcomas/index.md) | ограничения объёма резекции, доля лучевой терапии, иной состав подтипов |
| [Забрюшинные саркомы](retroperitoneal-sarcoma/index.md) | резекция единым блоком со смежными органами, преобладание липосарком |
| [Саркомы молочной железы](breast-sarcomas/index.md) | отграничение от филлодных опухолей и от радиационно-ассоциированных |
| [Первичные саркомы сердца](primary-cardiac-sarcomas/index.md) | резектабельность определяется анатомией, а не размером |

## Перемещено

Хордома отнесена к разделу [Саркомы костей](../bone-sarcomas/chordoma/index.md):
опухоль исходит из остатков хорды в осевом скелете, и её лечение определяется
хирургией позвоночника и основания черепа.
