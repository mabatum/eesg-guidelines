# Саркомы мягких тканей

**Статус:** Тестовая версия · **Обновлено:** 16.08.2026


Раздел построен по гистологической оси. Страницы расположены в порядке
убывания заболеваемости, поэтому нозологии, с которыми врач сталкивается чаще,
стоят выше. Опухоли, выделяемые по локализации, и нозологии с собственным
алгоритмом лечения вынесены в раздел
[Отдельные нозологические группы](../specific-tumor-groups/index.md).

**Диагноз подтверждается морфологически и, для подтипов с определяющей перестройкой, молекулярно до начала лечения.** [[1]](https://doi.org/10.1186/1471-2407-10-150)

> Полное расхождение первичного и экспертного заключения встречается почти в
> пятой части наблюдений, а с учётом расхождений по степени и подтипу пересмотр
> меняет заключение почти в половине случаев. Порядок направления и пересмотра
> изложен в разделе [Общие принципы](../general-principles/index.md).

| Гастроинтестинальные стромальные опухоли, саркомы матки, десмоидные опухоли, дерматофибросаркома протуберанс, солитарная фиброзная опухоль, саркома Капоши | [Отдельные нозологические группы](../specific-tumor-groups/index.md) |

| Саркомы кости, включая хордому | [Саркомы костей](../bone-sarcomas/index.md) |
| Незапланированное удаление, олигометастатическое заболевание, беременность, пожилой возраст, радиационно-ассоциированные саркомы | [Отдельные клинические ситуации](../special-clinical-situations/index.md) |

> Саркомы головы и шеи и забрюшинные саркомы выделены по локализации, а не по
> гистологическому типу, поэтому места в перечне по частоте не имеют. Внутри
> них встречаются те же нозологии, что перечислены выше.
