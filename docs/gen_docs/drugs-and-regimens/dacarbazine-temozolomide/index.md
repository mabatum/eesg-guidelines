| Показатель | Значение |
|---|---|
| Дакарбазин в монотерапии | активность низкая: выживаемость без прогрессирования 1,5–2 месяца [[1]](https://doi.org/10.1200/JCO.2015.62.4734) [[2]](https://doi.org/10.1200/JCO.2010.33.6107) |

| Дакарбазин как препарат сравнения | использовался в исследованиях трабектедина и эрибулина [[1]](https://doi.org/10.1200/JCO.2015.62.4734) [[4]](https://doi.org/10.1016/S0140-6736(15)01283-0) |

## Дакарбазин

**В монотерапии дакарбазин малоактивен и служил препаратом сравнения в исследованиях последующих линий.** [[1]](https://doi.org/10.1200/JCO.2015.62.4734) [[4]](https://doi.org/10.1016/S0140-6736(15)01283-0)

> Медиана выживаемости без прогрессирования составила 1,5 месяца в исследовании
> трабектедина; именно на этом фоне оценивались более активные препараты.

**Дакарбазин применяется в сочетании с гемцитабином, а не в монотерапии.** [[2]](https://doi.org/10.1200/JCO.2010.33.6107)

| Показатель [[2]](https://doi.org/10.1200/JCO.2010.33.6107) | Гемцитабин с дакарбазином | Дакарбазин |
|---|---|---|
| Доля живых без прогрессирования к 3 месяцам | 56 % | 37 % |
| Медиана выживаемости без прогрессирования | 4,2 месяца | 2 месяца |
| Отношение рисков прогрессирования | 0,58 (95 % ДИ 0,39–0,86) | сравнение |
| Медиана общей выживаемости | 16,8 месяца | 8,2 месяца |
| Отношение рисков смерти | 0,56 (95 % ДИ 0,36–0,90) | сравнение |
| Объективный ответ или стабилизация | 49 % | 25 % |

| Режим [[2]](https://doi.org/10.1200/JCO.2010.33.6107) | Значение |
|---|---|
| Гемцитабин | 1800 мг/м² с фиксированной скоростью введения 10 мг/м² в минуту |
| Дакарбазин | 500 мг/м² |
| Интервал | каждые 2 недели |
| Дакарбазин в монотерапии | 1200 мг/м² каждые 3 недели |

**Тяжёлая токсичность при сочетании нечаста; прекращение лечения из-за неё редко.** [[2]](https://doi.org/10.1200/JCO.2010.33.6107)

> Наиболее частым тяжёлым явлением была гранулоцитопения, фебрильная нейтропения
> встречалась редко.

## Темозоломид

**Темозоломид — пероральный аналог дакарбазина; при саркомах применяется преимущественно в сочетаниях.** [[3]](https://doi.org/10.1002/cncr.26098)

**При солитарной фиброзной опухоли темозоломид назначается с бевацизумабом.** [[3]](https://doi.org/10.1002/cncr.26098)

| Режим [[3]](https://doi.org/10.1002/cncr.26098) | Значение |
|---|---|
| Темозоломид | 150 мг/м² внутрь в дни 1–7 и 15–21 |
| Бевацизумаб | 5 мг/кг внутривенно в дни 8 и 22 |
| Цикл | 28 дней |

| Результат [[3]](https://doi.org/10.1002/cncr.26098) | Значение |
|---|---|
| Частичный ответ по критериям Чоя | 79 % |
| Медиана времени до ответа | 2,5 месяца |
| Медиана выживаемости без прогрессирования | 9,7 месяца |
| Ведущая токсичность | миелосупрессия |

> Подробнее — на странице
> [Солитарная фиброзная опухоль](../../specific-tumor-groups/solitary-fibrous-tumor/index.md).

**При лейомиосаркоме темозоломид изучается в сочетании с кабозантинибом.** [[5]](https://doi.org/10.1016/S1470-2045(25)00654-0)

| Показатель при лейомиосаркоме [[5]](https://doi.org/10.1016/S1470-2045(25)00654-0) | Значение |
|---|---|
| Доля живых без прогрессирования к 12 неделям | 74 % |
| Тромбоцитопения 3–4 степени | 30 % |
| Нейтропения 3–4 степени | 18 % |
| Артериальная гипертензия 3–4 степени | 10 % |

**Вне исследования сочетание с кабозантинибом стандартом не является.** — согласованное мнение рабочей группы

## Токсичность и её ведение

| Явление | Что делать |
|---|---|
| Тошнота и рвота | дакарбазин высокоэметогенен: трёхкомпонентная профилактика |
| Миелосупрессия | общий анализ крови перед каждым введением |
| Боль по ходу вены и флебит | медленное введение, при повторении — центральный доступ |
| Гепатотоксичность | печёночные пробы перед курсом |
| Лимфопения при темозоломиде | профилактика пневмоцистной пневмонии при длительном приёме |

**Дакарбазин вводится в разведении и под защитой от света.** — согласованное мнение рабочей группы

## Что проверить до начала

| Что | Зачем |
|---|---|
| Гистологический подтип | активность ограничена лейомиосаркомой и солитарной фиброзной опухолью |
| Общий анализ крови | миелосупрессия |
| Печёночные пробы | гепатотоксичность |
| План противорвотной профилактики | высокая эметогенность |
| Венозный доступ | флебит при периферическом введении |

## Ограничения доказательной базы

**Преимущество сочетания с гемцитабином установлено в исследовании второй фазы у 113 больных.** [[2]](https://doi.org/10.1200/JCO.2010.33.6107)

**Данные о темозоломиде при солитарной фиброзной опухоли получены ретроспективно, оценка ответа проводилась по критериям Чоя, а не RECIST.** [[3]](https://doi.org/10.1002/cncr.26098)

**Исследование сочетания с кабозантинибом было одногрупповым, без сравнения.** [[5]](https://doi.org/10.1016/S1470-2045(25)00654-0)

**Собственных исследований дакарбазина как активного препарата не проводилось: его роль установлена по группам сравнения.** [[1]](https://doi.org/10.1200/JCO.2015.62.4734) [[4]](https://doi.org/10.1016/S0140-6736(15)01283-0)

## Сопоставление с действующими руководствами

| Сообщество | Позиция по дакарбазину и темозоломиду |
|---|---|
| ESMO | дакарбазин приводит в последующих линиях, в том числе в сочетании с гемцитабином; отмечает активность при лейомиосаркоме и солитарной фиброзной опухоли |
| NCCN | по первоисточнику не сверялось |
| Британское руководство (BSG) | приводит дакарбазин в последующих линиях; при солитарной фиброзной опухоли называет темозоломид с бевацизумабом |
| Немецкое руководство (GGPO) | приводит дакарбазин при лейомиосаркоме |
| Рабочая группа EESG | дакарбазин в монотерапии не назначает; при солитарной фиброзной опухоли применяет темозоломид с бевацизумабом |

> Расхождений нет. Отказ от монотерапии дакарбазином сформулирован здесь прямо:
> рандомизированное сравнение показало вдвое худшую выживаемость без
> прогрессирования и вдвое худшую общую выживаемость по сравнению с сочетанием.
