## Периоперационное лечение

**Периоперационный режим состоит из эпирубицина 120 мг/м² и ифосфамида 9 г/м² за курс; проводится 3 курса.** [[1]](https://doi.org/10.1016/S1470-2045(17)30334-0)

| Параметр [[1]](https://doi.org/10.1016/S1470-2045(17)30334-0) | Значение |
|---|---|
| Эпирубицин | 120 мг/м² за курс |
| Ифосфамид | 9 г/м² за курс с месной |
| Число курсов | 3 |
| Интервал | 3 недели |
| Колониестимулирующий фактор | обязателен |

**Подбор режима по гистологическому типу преимущества перед этим режимом не дал.** [[1]](https://doi.org/10.1016/S1470-2045(17)30334-0)

| Выживаемость без признаков болезни [[1]](https://doi.org/10.1016/S1470-2045(17)30334-0) | Стандартный режим | Режим по гистологическому типу |
|---|---|---|
| К 46 месяцам | 62 % | 38 % |
| Отношение рисков | сравнение | 2,00 (95 % ДИ 1,22–3,26) |

> Исследование закрыто досрочно после третьего анализа бесполезности. Выигрыш
> стандартного режима расценён как вклад самой предоперационной химиотерапии.

**Режим выполним и у больных 65 лет и старше.** [[3]](https://doi.org/10.1200/JCO.2015.62.9394)

> Дозовая интенсивность превысила 90 % и в этой возрастной группе, и при
> одновременном облучении.

## Сочетание с предоперационным облучением

**Химиотерапия и облучение проводятся одновременно, если это позволяет не откладывать операцию.** [[4]](https://doi.org/10.1158/1078-0432.CCR-26-0400) [[3]](https://doi.org/10.1200/JCO.2015.62.9394)

| Показатель | Химиотерапия с облучением | Химиотерапия одна |
|---|---|---|
| Объективный ответ по RECIST [[4]](https://doi.org/10.1158/1078-0432.CCR-26-0400) | 20,3 % | 9,8 % |
| Расхождение раны [[4]](https://doi.org/10.1158/1078-0432.CCR-26-0400) | 9 % | 3,5 % |
| Серома [[4]](https://doi.org/10.1158/1078-0432.CCR-26-0400) | 10,4 % | 2,8 % |
| Раневые осложнения [[3]](https://doi.org/10.1200/JCO.2015.62.9394) | 17 % | 10 % |
| Гематологическая токсичность | сопоставима | сопоставима |

**Больной предупреждается о раневых осложнениях до начала лечения.** — согласованное мнение рабочей группы

## Распространённое заболевание

**При распространённом заболевании сочетание назначается только тогда, когда целью служит регрессия опухоли.** [[2]](https://doi.org/10.1016/S1470-2045(14)70063-4)

| Показатель [[2]](https://doi.org/10.1016/S1470-2045(14)70063-4) | Доксорубицин с ифосфамидом | Доксорубицин |
|---|---|---|
| Объективный ответ | 26 % | 14 % |
| Медиана выживаемости без прогрессирования | 7,4 месяца | 4,6 месяца |
| Медиана общей выживаемости | 14,3 месяца | 12,8 месяца (различие незначимо) |

| Режим при распространённом заболевании [[2]](https://doi.org/10.1016/S1470-2045(14)70063-4) | Значение |
|---|---|
| Доксорубицин | 25 мг/м² в сутки в дни 1–3 |
| Ифосфамид | 10 г/м² за курс с месной |
| Интервал | 3 недели |
| Колониестимулирующий фактор | обязателен |

**Больным 60 лет и старше сочетание не назначается.** [[5]](https://doi.org/10.1200/JCO.20.00714) [[2]](https://doi.org/10.1016/S1470-2045(14)70063-4)

## Ограничения доказательной базы

**Периоперационный режим изучен у больных высокого риска с саркомами конечностей и поверхностных отделов туловища; на другие локализации он не переносится.** [[1]](https://doi.org/10.1016/S1470-2045(17)30334-0)

**Сравнения трёх курсов с большим их числом в этом исследовании не проводилось.** [[1]](https://doi.org/10.1016/S1470-2045(17)30334-0)

**Данные об одновременном облучении получены в подгруппе, где выбор облучения не распределялся случайным образом.** [[4]](https://doi.org/10.1158/1078-0432.CCR-26-0400)

**В исследовании при распространённом заболевании применялся доксорубицин, а в периоперационном — эпирубицин; прямого сравнения антрациклинов между собой не проводилось.** [[2]](https://doi.org/10.1016/S1470-2045(14)70063-4) [[1]](https://doi.org/10.1016/S1470-2045(17)30334-0)

## Сопоставление с действующими руководствами

| Сообщество | Позиция по сочетанию антрациклина с ифосфамидом |
|---|---|
| ESMO | формального доказательства превосходства многокомпонентной химиотерапии над монотерапией доксорубицином по общей выживаемости не признаёт; сочетание рассматривает при необходимости уменьшить опухоль |
| NCCN | по первоисточнику не сверялось |
| Британское руководство (BSG) | периоперационную химиотерапию допускает у больных высокого риска и при потенциально более химиочувствительных подтипах |
| Немецкое руководство (GGPO) | сочетание доксорубицина 75 мг/м² с ифосфамидом 5 г/м² оптимальным не считает |
| Рабочая группа EESG | периоперационный режим приводит с дозами: эпирубицин 120 мг/м² и ифосфамид 9 г/м² за курс, 3 курса; при распространённом заболевании сочетание назначает только ради регрессии опухоли, больным 60 лет и старше — не назначает |

> Расхождений нет. Дозы периоперационного режима приведены здесь по протоколу
> исследования, в котором он показал выигрыш; руководства ограничиваются
> указанием на антрациклин с ифосфамидом без числовых значений.
