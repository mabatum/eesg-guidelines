# Эрибулин

**Статус:** Тестовая версия · **Обновлено:** 17.08.2026


| Показатель | Значение |
|---|---|
| Место | липосаркома после антрациклина и ещё одной линии [[1]](https://doi.org/10.1200/JCO.2016.71.6605) |
| Доза | 1,4 мг/м² внутривенно в 1-й и 8-й дни каждые 3 недели [[1]](https://doi.org/10.1200/JCO.2016.71.6605) |
| Общая выживаемость при липосаркоме против дакарбазина | 15,6 против 8,4 месяца [[1]](https://doi.org/10.1200/JCO.2016.71.6605) |
| Выживаемость без прогрессирования при липосаркоме | 2,9 против 1,7 месяца [[1]](https://doi.org/10.1200/JCO.2016.71.6605) |
| При лейомиосаркоме | выигрыш не показан [[2]](https://doi.org/10.1016/S0140-6736(15)01283-0) [[1]](https://doi.org/10.1200/JCO.2016.71.6605) |
| Подтипы липосаркомы с доказанным выигрышем | дедифференцированная, миксоидная и круглоклеточная, плеоморфная [[1]](https://doi.org/10.1200/JCO.2016.71.6605) |

## Место в лечении

**Эрибулин применяется при липосаркоме после антрациклина.** [[1]](https://doi.org/10.1200/JCO.2016.71.6605)

| Показатель при липосаркоме [[1]](https://doi.org/10.1200/JCO.2016.71.6605) | Эрибулин | Дакарбазин |
|---|---|---|
| Медиана общей выживаемости | 15,6 месяца | 8,4 месяца |
| Отношение рисков смерти | 0,51 (95 % ДИ 0,35–0,75) | сравнение |
| Медиана выживаемости без прогрессирования | 2,9 месяца | 1,7 месяца |
| Отношение рисков прогрессирования | 0,52 (95 % ДИ 0,35–0,78) | сравнение |

**Выигрыш получен во всех гистологических подтипах липосаркомы.** [[1]](https://doi.org/10.1200/JCO.2016.71.6605)

**При лейомиосаркоме преимущества эрибулина не показано; выигрыш в общем исследовании обеспечен подгруппой липосаркомы.** [[2]](https://doi.org/10.1016/S0140-6736(15)01283-0) [[1]](https://doi.org/10.1200/JCO.2016.71.6605)

> Это редкий для сарком случай, когда препарат увеличивает общую выживаемость, а
> не только контроль болезни, — но только при одном гистологическом типе.

**Гистологический подтип уточняется до назначения.** — согласованное мнение рабочей группы

> При лейомиосаркоме после антрациклина рассматриваются другие варианты; см.
> [Трабектедин](../trabectedin/index.md) и
> [Гемцитабин с доцетакселом](../gemcitabine-docetaxel/index.md).

## Режим

| Параметр | Значение |
|---|---|
| Доза | 1,4 мг/м² [[1]](https://doi.org/10.1200/JCO.2016.71.6605) |
| Дни введения | 1-й и 8-й |
| Интервал | 3 недели |
| Путь введения | внутривенно |
| Линия | третья и последующие: требовались две предшествующие линии, включая антрациклин [[1]](https://doi.org/10.1200/JCO.2016.71.6605) |
| Длительность | до прогрессирования или неприемлемой токсичности |

## Токсичность

| Явление | Что делать |
|---|---|
| Нейтропения | общий анализ крови перед каждым введением, включая 8-й день |
| Периферическая нейропатия | оценка перед каждым курсом; при 2 степени и выше — снижение дозы или перерыв |
| Утомляемость | оценка функционального статуса перед курсом |
| Удлинение интервала QT | электрокардиограмма при сопутствующей терапии, влияющей на интервал |
| Коррекция электролитов | калий и магний до начала лечения |

**Введение 8-го дня выполняется только после контроля анализа крови.** — согласованное мнение рабочей группы

**Профиль нежелательных явлений сопоставим с дакарбазином.** [[1]](https://doi.org/10.1200/JCO.2016.71.6605)

## Что проверить до начала

| Что | Зачем |
|---|---|
| Гистологический подтип | выигрыш доказан только при липосаркоме [[1]](https://doi.org/10.1200/JCO.2016.71.6605) |
| Число и состав предшествующих линий | препарат изучен после двух линий, включая антрациклин [[1]](https://doi.org/10.1200/JCO.2016.71.6605) |
| Исходная неврологическая оценка | нейропатия |
| Общий анализ крови | нейтропения |
| Калий, магний, электрокардиограмма | удлинение интервала QT |

## Ограничения доказательной базы

**Выигрыш при липосаркоме получен в подгрупповом анализе, хотя подгруппа рандомизировалась отдельно и была предусмотрена протоколом.** [[1]](https://doi.org/10.1200/JCO.2016.71.6605)

**При лейомиосаркоме, составлявшей большинство включённых больных, выигрыша нет.** [[2]](https://doi.org/10.1016/S0140-6736(15)01283-0)

**Сравнение проводилось с дакарбазином, а не с трабектедином или гемцитабином с доцетакселом.** [[2]](https://doi.org/10.1016/S0140-6736(15)01283-0) [[3]](https://doi.org/10.1200/JCO.2015.62.4734)

**Больные получали не менее двух предшествующих линий, поэтому на более ранние линии результат не переносится.** [[1]](https://doi.org/10.1200/JCO.2016.71.6605) [[4]](https://doi.org/10.1016/S1470-2045(14)70063-4)

## Сопоставление с действующими руководствами

| Сообщество | Позиция по эрибулину |
|---|---|
| ESMO | эрибулин зарегистрирован для второй и последующих линий; отмечает, что выигрыш получен преимущественно при липосаркоме |
| NCCN | по первоисточнику не сверялось |
| Британское руководство (BSG) | приводит регистрацию эрибулина при нерезектабельной липосаркоме после антрациклинсодержащей терапии |
| Немецкое руководство (GGPO) | приводит эрибулин при липосаркоме после антрациклина |
| Рабочая группа EESG | назначает эрибулин при липосаркоме; при лейомиосаркоме не назначает |

> Расхождений нет. Отказ от применения при лейомиосаркоме сформулирован здесь
> прямо: в исследовании эта подгруппа была большей, и выигрыша в ней не получено.
