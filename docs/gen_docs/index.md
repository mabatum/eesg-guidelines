# Клинические рекомендации EESG по диагностике и лечению сарком

**Статус:** Тестовая версия · **Обновлено:** 15.08.2026


## Введение

Саркомы объединяют биологически неоднородную группу злокачественных опухолей мезенхимального происхождения, различающихся по морфологическому строению, молекулярным нарушениям, анатомической локализации, характеру метастазирования и чувствительности к противоопухолевому лечению. Диагностика и выбор лечебной тактики требуют участия специализированной многопрофильной команды и морфологического пересмотра в учреждении, располагающем опытом ведения больных саркомами. [европейские рекомендации по диагностике и лечению сарком мягких тканей, 2021](https://doi.org/10.1016/j.annonc.2021.07.006); [Британская саркомная группа, 2024](https://doi.org/10.1038/s41416-024-02674-y).

Настоящие рекомендации предназначены для диагностики, лечения и наблюдения пациентов в возрасте 18 лет и старше. При саркоме Юинга, остеосаркоме, неплеоморфной рабдомиосаркоме и некоторых редких молекулярно-определяемых опухолях значительная часть исследований выполнена в смешанных возрастных когортах; применимость таких результатов к взрослым оценивается отдельно для каждого клинического вопроса. [Британские рекомендации по саркомам костей, 2024](https://doi.org/10.1038/s41416-024-02868-4); [рекомендации Испанской группы по исследованию сарком по саркоме Юинга, 2024](https://doi.org/10.1007/s12094-024-03602-5).

## Область применения

Рекомендации охватывают:

- организацию специализированной помощи;
- морфологическую и молекулярно-генетическую диагностику;
- визуализацию и определение распространённости заболевания;
- хирургическое и лучевое лечение;
- лекарственную терапию;
- наблюдение после завершения лечения;
- отдельные клинические ситуации и возрастные особенности применения результатов исследований.
