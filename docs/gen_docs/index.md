# Клинические рекомендации EESG

**Статус:** Тестовая версия · **Обновлено:** 17.08.2026

Рекомендации Восточно-Европейской группы по изучению сарком по диагностике, лечению и наблюдению.

Материалы представлены для профессионального обсуждения.

## [Саркомы костей](bone-sarcomas/index.md)

Диагностика и лечение первичных опухолей кости у взрослых.

- [Общие принципы ведения первичных опухолей кости](bone-sarcomas/general-principles/index.md) — маршрут больного, биопсия, стадирование, общая тактика
- [Остеосаркома](bone-sarcomas/osteosarcoma-adults/index.md) — локализованное и распространённое заболевание
- [Хондросаркома](bone-sarcomas/chondrosarcoma-adults/index.md) — хирургическая тактика, отдельные подтипы
- [Саркома Юинга](bone-sarcomas/ewing-sarcoma-adults/index.md) — мультимодальное лечение, системная терапия

- [Хордома](bone-sarcomas/chordoma/index.md) — локальное лечение, распространённое заболевание
- [Редкие опухоли кости](bone-sarcomas/rare-bone-tumours/index.md) — практические положения по редким нозологиям

## Как оставить замечание

Регистрация не нужна; искать нужное место в тексте и писать письмо тоже не нужно.

1. Выделите фрагмент текста на любой странице.
2. Нажмите появившуюся кнопку **«Замечание»**.
3. Напишите, что не так, и отправьте. Имя и место работы — по желанию.

Замечание уходит рабочей группе вместе с цитатой и адресом страницы. Общее замечание к странице можно оставить кнопкой в правом нижнем углу.

## Как читать страницу

- **Полужирный абзац** — утверждение: что делать.
- **Абзац с отступом под ним** — доказательные детали: размер эффекта, доверительный интервал, ограничение.
- **Номер со ссылкой** — конкретное исследование, на котором основано утверждение.
- **Раздел «Сопоставление с действующими руководствами»** — позиции ESMO, NCCN, британского и немецкого руководств.
- **Раздел «Ограничения доказательной базы»** — чего эти данные не доказывают.
