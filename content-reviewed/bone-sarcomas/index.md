# Саркомы костей

**Статус:** Тестовая версия · **Версия:** 2026.09.3 · **Обновлено:** 24.09.2026

**Основа:** клинические рекомендации «Саркомы костей», 2025, взрослые, ID 532_5. Веб-редакция для профессионального обсуждения.

Рекомендации по диагностике, лечению и наблюдению взрослых пациентов с первичными опухолями кости. Клинические положения этой редакции приведены по документу **«Саркомы костей», 2025, ID 532_5**. Сохранены нозологические страницы и ссылки прежней версии сайта.

## Выбор тактики по гистологическому варианту

| Опухоль / клиническая ситуация | Тактика, представленная в КР 532_5 |
|---|---|
| Остеосаркома высокой степени злокачественности | Неоадъювантная химиотерапия, радикальная операция, послеоперационная химиотерапия |
| Паростальная остеосаркома | Радикальное хирургическое лечение |
| Периостальная остеосаркома | Радикальная операция; необходимость лекарственного лечения решает консилиум |
| Саркома Юинга | Комбинированная химиотерапия и локальное лечение — операция и/или лучевая терапия |
| Дедифференцированная хондросаркома | Режимы и последовательность химиотерапии, принятые для остеосаркомы |
| Мезенхимальная хондросаркома | Режимы и последовательность химиотерапии, принятые для саркомы Юинга |
| Неоперабельная прогрессирующая классическая хондросаркома | В КР перечислены дазатиниб и пазопаниб |
| Гигантоклеточная опухоль кости | Планирование объёма операции; неоадъювантный деносумаб, при неоперабельном процессе — длительная терапия |
| Неоперабельная клинически значимая / прогрессирующая хордома | В КР перечислены иматиниб, дазатиниб, сунитиниб |

[КР 532_5, разд. 3, 3.2.1–3.2.3, с. 21–39](https://mabatum.github.io/eesg-guidelines/_assets/sources/kr532-5-2025.pdf#page=22) [КР 532_5, разд. 3.3, с. 40–43](https://mabatum.github.io/eesg-guidelines/_assets/sources/kr532-5-2025.pdf#page=41)

## Как пользоваться источником

Рядом с клиническими блоками указаны раздел и страницы КР. Уровень убедительности рекомендаций (УУР) и уровень достоверности доказательств (УДД) сохранены там, где в исходном документе они относятся к конкретному положению. Они не переназначались по результатам редакционного пересказа.

Схемы приведены с дозами и календарями исходного документа. Обозначение **†** сохраняет знак **#** у препарата в КР; при назначении необходимо учитывать регистрационные показания и инструкцию конкретного препарата. Дозы, противопоказания и меры предосторожности оценивают с учётом состояния пациента. [КР 532_5, разд. 3, с. 21](https://mabatum.github.io/eesg-guidelines/_assets/sources/kr532-5-2025.pdf#page=22)

Полный PDF содержит также номенклатуру медицинских услуг, состав рабочей группы, методологию, список литературы и оригинальные алгоритмы. [Алгоритмы диагностики и лечения](https://mabatum.github.io/eesg-guidelines/_assets/sources/kr532-5-2025.pdf#page=72) — приложение Б, с. 71–73.

## Что изменилось

- Клиническая основа всех костных страниц заменена на КР 532_5, 2025.
- Схемы AP, послеоперационная тактика при остеосаркоме, VAC/IE, повторные линии и лучевая терапия приведены по этому документу.
- Обновлены рекомендации по деносумабу и наблюдению.
- Положения прежней редакции, отсутствующие в КР 532_5, не представлены как положения нового источника.
- Замечания можно отправлять прямо с сайта без входа в GitHub или Google. Выделенная цитата и ссылка на раздел передаются редактору вместе с замечанием.
